# M.S. Car Rent — Full-Stack Car Rental Web Application

https://adam-radi.vercel.app


**M.S. Car Rent** is a full-stack car rental web application designed to manage vehicles, customers, bookings, employees and rental operations through a modern web interface.

The project demonstrates full-stack development using **React.js, Node.js, Express.js and MongoDB**.

## Project Overview

M.S. Car Rent provides a digital platform for a car rental business.

The application includes customer-facing rental workflows and administrative management features for vehicles, bookings, users and notifications.

## Key Features

- Car rental management
- Vehicle management
- Customer management
- Employee management
- Booking management
- Pickup location management
- Vehicle availability
- Pricing and discounts
- Notifications
- User authentication
- Role-based access
- Admin dashboard
- Responsive interface
- Multi-language support
- PDF-related functionality
- Email functionality
